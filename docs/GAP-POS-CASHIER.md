# تحليل فجوات شاشة الكاشير ونقطة البيع (POS) وربطها بخطة العمل

> **المصدر:** `docs/ezees-guide/pos-cashier.txt` (دليل Ezees ERP — "شاشة الكاشير ونقطة البيع"، آخر تحديث بالمصدر: 2026-10-10).
>
> **مقارنة مع:** شاشة الكاشير الحالية في WaselERP (`apps/web/app/pos/page.tsx` بعد إعادة التصميم بـ UI/UX Pro Max) والـ API (`apps/api/src/modules/sales/sales.slice.ts`, `pricing/pricing.slice.ts`).
>
> **حالة هذه النسخة:** التحليل + تنفيذ الفجوات القابلة للتطبيق (نافذة الدفع، الهدايا، الكوبونات، الخصم الجماعي، الاختصارات، النسخة الاحتياطية للسلة) — 2026-11-14.

## 1) ملخص تنفيذي

| المؤشر | النتيجة |
|---|---|
| أجزاء الشاشة في الدليل | 6 تبويبات رئيسية (الأصناف، الطاولات، الإدخال، الفواتير المؤقتة، العميل، الدفع) |
| موجود قبل هذا التحديث | ≈60% — سلة، باركود/بحث، وحدات متعددة، خصم سطر، كوبونات خلفية، وردية، HVAC مرتجعات، معلّقات، طرق دفع، طباعة |
| أُضيف في هذا التحديث | **نافذة الدفع (المدفوع/الباقي)** + **اختصارات F1/F2/F4/F6/F7** + **سطر هدية (isGift) بصلاحية `sales.giveaway`** + **كوبون من شاشة البيع** + **خصم على كل الأصناف (٪/مبلغ)** + **فتح درج النقود** + **آخر فاتورة + عدد القطع** + **حفظ السلة على الجهاز واستعادتها** |
| غير منطقي/خارج النطاق حاليًا | شاشة عرض العميل (COM/سيريال)، مودم الطلبات الهاتفية، التعامل مع وزن الميزان، «نمط متطور» للأعمدة، رمز اللغة (English UI)، متغيرات حالة الأسعار (جملة/نصف جملة/...)، بوابة ZATCA التلقائية |

## 2) مصفوفة الفجوات التفصيلية

### 2.1 قبل أن تبدأ البيع

| بند الدليل | الحالة في WaselERP | الملاحظة |
|---|---|---|
| وردية مفتوحة إلزامية للبيع | ✅ موجود — `RequireCashierShift` (افتراضي false) + شريط الوردية + فحص قبل الحفظ على السيرفر والواجهة | أفضل من الدليل (فحص مدمج بالواجهة والخادم) |
| المخزن الافتراضي إلزامي | ✅ موجود — ترحيل على `warehouses` وإلا لا تُحفظ الفاتورة (السيرفر يرفض) | — |
| الفرع/الصندوق أعلى الشاشة | ✅ موجود — في AppShell (اسم الفرع + الوردية) | — |
| الأصناف المعروضة = غير الموقوفة فقط | 🟡 جزئي — البحث يرجع غير الموقوفة (`items` module يقفل `is_active`) | لا تصفية حسب الفئة المسموحة للكاشير |
| استعادة فاتورة غير محفوظة بعد انقطاع التيار/الإغلاق | ✅ **أُضيف** — `wasel.pos.draft` في localStorage + بانر «توجد فاتورة غير محفوظة» | الدليل مشروح بالتفصيل؛ التطبيق نفسه |

### 2.2 أجزاء الشاشة

| بند الدليل | الحالة | الملاحظة |
|---|---|---|
| شريط أدوات جديد/حفظ/حذف/طباعة/تحديث + بحث برقم الفاتورة | 🟡 جزئي — طباعة و"مرتجع برقم الفاتورة" موجود؛ لا يوجد بحث عام عن فاتورة سابقة لفتحها/حذفها من داخل الكاشير (موجود في شاشة «الفواتير») | إضافة F-keys تغطيه |
| تبويب الاصناف (أزرار لمس للفئات والأصناف) | ❌ غير منفذ كأزرار فئات؛ للبيع السريع باللمس يحتاج لوحة مفاتيح/ماسح أو بحث | غير منطقي v1 |
| تبويب الطاولات (وضع المطاعم) | ✅ موجود في `/restaurant` (وضع المطاعم بأكواده المستقل) | — |
| لوحة الإدخال (باركود، الصنف، الوحده، الكمية، نوع السعر...) | 🟡 جزئي — لا يوجد اختيار «نوع السعر» (نقدي/جملة/نصف جملة) إلا عمدًا (غير مطلوب في السوق) | — |
| جدول أصناف الفاتورة + «نمط متطور» (خصم % + مبلغ) | ✅ منجز أساسيًا — خصم % على السطر، لا نمط متبادل للأعمدة | — |
| تبويب العميل (الهاتف/الاسم/العنوان/المنطقة/السائق) | ✅ جزئي — `/restaurant` يُظهر حقول العميل للتوصيل؛ الكاشير العادي يختار العميل فقط | — |
| تبويب فواتير مؤقتة (تعليق) | ✅ موجود — تعليق واسترجاع Universal (parkCart, resumeCart) | — |
| أسفل الفاتورة: الإجمالي/الخصم/توصيل/ضريبة/مباشر أو توصيل | ✅ موجود | — |
| لوحة الدفع: رقم/تاريخ/مبيعات/مرتجع/طريقة/البنك/مسدد/متبقى/الصافي | ✅ جزئي — نافذة دفع (بمسدد/متبقي) أُضيفت الآن؛ لا يوجد «مبيعات/مرتجع» مفتاح إلا من وضع المرتجع | — |
| لوحة الأزرار: جديد/حفظ/ف مؤقتة/+ - /هدية/حذف/خصم/كوبون/درج | ✅ موجود — جديد (إفراغ)، + −، هدية **(أُضيفت)**، حذف، خصم جماعي **(أُضيف)**، كوبون **(أُضيف)**، فتح الدرج **(أُضيف)** | — |

## 3) الخلاصة والأولويات

### منجز في هذه الدفعة
1. نافذة الدفع (المدفوع/الباقي) مع Enter/Esc/F7.
2. اختصارات لوحة المفاتيح F1/F2/F4/F6/F7.
3. سطور هدية (`isGift`) بصلاحية `sales.giveaway` + إظهارها خضراء.
4. كوبون على شاشة البيع (يمرر `couponCode` للخادم).
5. خصم % أو مبلغ على كل الأصناف (مبلغ يتوزع بالتساوي).
6. فتح درج النقود (ESC/POS) + زر إفراغ + عدد القطع + آخر فاتورة.
7. حفظ السلة على الجهاز (`wasel.pos.draft`) + عرض استعادتها.

### المتبقي عالي القيمة (مقترح للمرحلة القادمة)
- اختيار نوع السعر (نقدي/جملة/نصف جملة) وقائمة الأسعار اليدوية.
- Batch No وعمولة البنك للدفع بالشبكة.
- F-keys الوصول لفاتورة سابقة للطباعة/التعديل من نفس الشاشة.
- منع البيع الآجل على «العميل النقدي» الافتراضي تلقائيًا.
- موعد تسليم مقترح للتوصيل + شاشة تنبيهات التسليم.
- إشعارات ZATCA التلقائية بعد الحفظ (عند الربط).

### خارج النطاق حاليًا (بأسباب معمارية/سوقية)
- أزرار الفئات والأصناف الملمسية (بحاجة طلب سوقي؛ حالياً بحث+scanning hurtig).
- شاشة عرض العميل ومودم الهاتف والبركود بوزن (COM/أجهزة).
- «نمط متطور» (مسلسل/تاريج) كقيمة في جدول الأصناف نفسه.
- العملة الأجنبية لكل سطر وتحويل فوري (لا يوجد FX per-line).
