## ثانيًا: الوظائف من الدليل (`pos-cashier.txt`) — ما هو منفذ وما هو لا

### ✅ منفذة (نشطة)
- وردية مفتوحة إلزامية للبيع (سياسة قابلة للإيقاف من الأدمن — `RequireCashierShift`)
- مخزن افتراضي للفرع يُجبر الكاشير على الاختيار قبل الحفظ
- الأصناف غير الموقوفة فقط تظهر في البحث
- 6 خطوات بيع (F1 → الأصناف → الكمية → الدفع → F2 → إيصال)
- دعم الباركود ببحث بالاسم/الكود
- قدرة كل سكان الوحدة على نفس الرصيد (كرتونة/قطعة)
- خصم بالسطر + خصم جماعي (٪/مبلغ) + كوبون
- هدية مجانية للعميل (صلاحية `sales.giveaway`)
- اختيار العميل/النقدي الافتراضي/الآجل (بحد ائتمان)
- طباعة الإيصال بعد الحفظ (وكيل ESC/POS أو المتصفح)
- فواتير معلّقة (استرجاعها من «الفواتير المعلّقة»)
- مرتجع البيع من شاشة الكاشير
- سلة غير متصلة بالإنترنت + مزامنة تلقائية
- استعادة فاتورة غير محفوظة بعد انقطاع الكهرباء
- تحديث البيانات اللحظي بين الفروع (SSE)
- حقل ملاحظات للصنف/الفاتورة
- تبعّ فيزا/فيزا + نقدي + محفظة → دفع متعدد (نقدي + بطاقة في نفس الفاتورة)

### 🟡 جزئية أو مخالفة للسلوك الأصلي
- **وحدات الباركود**: الباركود الكبير/الصغير للمنتج لا يفرق وحدة البيع تلقائيًا (يُضاف بوحدة الصنف الافتراضية)
- **نوع السعر**: لا يوجد تبديل نقدي/آجل بسعر مختلف لكل سطر؛ الكاشير يحرر سعر البيع ضمن حد `minPrice` وقائمة أسعار العميل
- **طباعة مطبخ/تحرير شريك**: للنظام /restaurant حقل منفصل لكن ليس تحت نفس واجهة الكاشير
- **مفتاح الشبكة/الدفع بالفيزا**: لا يوجد حقل `BatchNo` للمعاملة أو نسبة تقريب؛ الدفع بالبطاقة يُسجل كوسيلة دفع عادية
- **العميل الافتراضي**: نظير لـ «العميل العادي» لا يُسمى صراحة «الافتراضي» في الواجهة (اسم العميل يظهر أو يُترك فارغًا)
- **عرض معالم العميل في البحث**: البحث يعرض الاسم + الرصيد + الهاتف، لكن لا يعرض «القائمة/التصنيف» بدونفتح شاشة العملاء

### ❌ غير منفذة (بالأسباب)
| الوظيفة | السبب |
|---|---|
| **نقدي / جملة / نصف جملة** (Radio) | يتطلب نموذج فئات أسعار مدمج لكل صنف (جملة، نصف، بيع) + شاشة إدارة + تقاطع مع الأسعار المتغيرة حسب العميل — تكرار وظيفي لـ «قوائم الأسعار» لدينا؛ لا يُبنى إلا بطلب سوقي إن أُلحّ |
| **شاشة عرض العميل** (LED البرمجية) | جهاز مستقل بمنفذ COM؛ لا يتوفر في المحلات الصغيرة. عند الحاجة: تُبنى كشاشة ثانية عبر المتصفح و `BroadcastChannel` |
| **مودم إظهار رقم المتصل (Caller ID)** | جهاز سوقت محلي (VoE/شبكة)؛ خارج قدرات الويب |
| **ميزان الباركود** (الأوزان) | يتطلب باركود الميزان (وزن داخل الكود) + قارئ خاص + ربط بالبرنامج؛ غير متوفر لنا حاليًا |
| **طباعة باركود للملصق** | يوجد في `/labels` (طباعة الملصقات) — ليست وظيفة الكاشير نفسه، ونقلت عمدًا |
| **خصم مستورد بالتباع** (batch / جملة) | نفس فجوة نوع السعر |
| **طباعة رفع الإيصال** (فضي/أزرق) | تصميم طباعة خاص؛ لا نُعدّل شكل الإيصال بدون طلب صريح |
| **أرشيف المبيعات مع الشركة** (تصدير دوري للمنظومة) | بوابة ZATCA قيد التنفيذ خارجيًا وطحنات مختلفة |

## ثالثًا: ما أُضيف في هذا الـ جرد (2026-11-14 حتى الآن)

1. ✅ أيقونة **تحديث البيانات** (إعادة تحميل الكتالوج فورًا)
2. ✅ **تاريخ الفاتورة** — حقل تاريخ فوق الشاشة، default اليوم، يقبل تواريخ سابقة
3. ✅ **خصم م** — زر «٪/ج» على كل سطر للتبديل بين نسبة٪ ومبلغ
4. ✅ **رقم الفاتورة — جديد** في نافذة الدفع (بدل تركها فارغة)
5. ✅ **قائمة المندوبين** (`/sales/reps`) + إرسال `repId` (يظهر فقط لو فيه مندوبون في الفرع)
6. ✅ **الهاتف** يظهر بجوار اسم العميل في نتائج البحث وفي اللوحة السفلية
