  • رسالة ترحيب العميل (SMS / Email / WhatsApp): تُرسل عند حفظ عميل جديد.
  • ارسال فاتورة البيع (Email / WhatsApp): يفعّل زري البريد وواتساب في معاينة الفاتورة، بشرط صلاحية المستخدم.
  • ارسال امر البيع: خيار متقدم – استشر الدعم الفني.

تبويب «ExtraModule»

محمي بكود وكلمة مرور الدعم الفني (Code وPassword ثم Log in). بعد الدخول تظهر خيارات تُظهر أو تُخفي أقسام القائمة الرئيسية، مثل Enable Sales Module وEnable HR Module. تُحفظ على الجهاز الحالي، وتظهر بعد إعادة تشغيل البرنامج.

لا تغيّر هذا التبويب إلا بتوجيه من الدعم الفني. إخفاء قسم يخفي قوائمه وأزراره من هذا الجهاز.

شاشة «اعدادات الاتصال» بقاعدة البيانات

تفتح من القائمة بـاعدادات السيرفر (تحتاج صلاحية الإعدادات)، وتظهر تلقائيًا عند تشغيل البرنامج إذا كانت بيانات الاتصال فارغة أو خاطئة. تُحفظ على الجهاز الحالي.

لمسؤول النظام فقط. الإعداد الخاطئ يجعل البرنامج يتصل بقاعدة بيانات أخرى أو لا يعمل. خذ نسخة احتياطية وسجّل البيانات الحالية قبل أي تغيير.
الإعدادماذا يفعلملاحظات
OnLine / OffLineOnLine: يعمل الجهاز على مجموعة اعدادات الاتصال (السيرفر الرئيسي). OffLine: يعمل على مجموعة اعدادات اتصال فرعى، أي قاعدة محلية للفرع تُزامَن مع الرئيسي.تغيير الوضع يتطلب إعادة تشغيل البرنامج.
نوع السيرفر (محلى / بعيد)هل السيرفر على نفس الشبكة أم بعيد عبر الإنترنت.على السيرفر البعيد تُقفل خيارات النسخ الاحتياطي.
عنوان السيرفراسم جهاز SQL Server أو عنوانه، مثل SERVER\SQLEXPRESS أو عنوان IP.
مصادقة الويندوز / مصادقة بهذه المعلوماتالدخول بحساب ويندوز، أو بمستخدم وكلمة مرور SQL Server.للأجهزة الأخرى في الشبكة استخدم المستخدم وكلمة المرور.
المستخدم / كلمة المروربيانات دخول SQL Server.تُحفظ كلمة المرور مشفرة.
قاعدة البياناتعند فتح القائمة تظهر قواعد بيانات Ezees ERP الموجودة على السيرفر فقط.
زر DB Cloud Listيعرض قواعد البيانات السحابية المسجلة لحسابك، واضافه يملأ بيانات الاتصال بها ويختبرها.يحتاج إنترنت وكود العميل.

الحفظ

  1. اضغط حفظ. يختبر البرنامج الاتصال أولًا، وإذا فشل تظهر بيانات الاتصال خاطئة ولا يُحفظ شيء.
  2. إذا تغيّر السيرفر أو قاعدة البيانات تُغلق الشاشات المفتوحة وتظهر شاشة تسجيل الدخول.
  3. إذا تغيّر وضع OnLine/OffLine تظهر رسالة لضمان تطبيق الاعدادات بنجاح يجب اعادة تشغيل النظام، ويعيد البرنامج التشغيل.

الضغط على F12 في هذه الشاشة يفتح أداة أوامر SQL. استخدمها بتوجيه من الدعم الفني فقط.

تبويب «اعداد السيرفر» (الاتصال عن بعد)

يظهر على جهاز السيرفر نفسه، ويضبط SQL Server لاستقبال اتصالات الأجهزة الأخرى.

  • اعداد السيرفر الحالى لاستقبال الاتصالات عن بعد: يفعّل الدخول بمستخدم SQL والمنفذ 1433 والاتصال عن بعد، ويفعّل المستخدم sa بكلمة المرور التي تكتبها في كلمة مرور السيرفر وتاكيد كلمة المرور.
  • اعداد السيرفر الحالى لمنع استقبال الاتصالات عن بعد: يغلق الاتصال عن بعد ويعطّل المستخدم sa.
  • اضغط موافق، ثم أعد تشغيل الجهاز كما تطلب الرسالة.
استخدم كلمة مرور قوية للمستخدم sa، ولا تفتح المنفذ 1433 على الإنترنت بدون جدار حماية. لا يعمل هذا الخيار من جهاز متصل بسيرفر بعيد أو بترخيص ثانوي: تظهر رسالة «لا يمكن عمل اعداد للسيرفر لانك متصل بسيرفر بعيد».

بعد الضغط على موافق تأكد من ظهور رسالة إعادة التشغيل. إذا لم تظهر فلم يُطبَّق الإعداد؛ تأكد من اختيار OnLine ومن صحة بيانات الاتصال.
