## قواعد الحفاظ على "تعديل كود قليل"

1. **قفل كل Gate** — لا يبدأ تنفيذ الـ Gate التالي قبل اجتياز الاختبارات.
2. **كل feature = وحدة مستقلة** + migration قبل الكود + اختبار انحدار في `tools/smoke-test.js`.
3. **الإعدادات/الأعمدة**: migration أول (أعمدة) ثم فهارس (إن لزم).
4. **لا تعديل دفتر مخزون من خارج `common/stock.ts`**.
5. **كل معاملة مالية**: `db.transaction()` + `common/posting.ts`.
6. **كل استعلام**: parameterized + casts صريحة.
7. **الواجهة**: أي تعديل → `npm run web:build`.
