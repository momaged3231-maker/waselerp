## الخطوات المرتبة (الأولوية)

### المرحلة 1 — Gate 0: نواة تشغيلية (P0) — ✅ منجزة
1. إصلاح صلاحيات البيع (OR للوظائف/AND للأنواع).
2. إصلاح تسوية المخزون السالبة (تخفيض ينقص).
3. تحديث التكلفة من فاتورة الشراء.
4. توحيد الوحدة الأساسية.
5. الرد العكسي للإلغاء.
6. اختبارات انحدار + ترحيل + `npm test` (127/127).

### المرحلة 2 — Gate 1: المحاسبة العامة (P1) — ✅ منجزة

2. سندات/شيكات/مراكز تكلفة/عملات/إقفال.
3. تقارير مالية.
4. ممنوعة: فروق الصرف، تقارير مراكز التكلفة التفصيلية.

### المرحلة 3 — Gate 2: دورة البيع والشراء (P2) — ✅ منجزة

## قواعد الحفاظ على "تعديل كود قليل"

1. **قفل كل Gate** — لا يبدأ تنفيذ الـ Gate التالي قبل اجتياز الاختبارات.
2. **كل feature = وحدة مستقلة** + migration قبل الكود + اختبار انحدار في `tools/smoke-test.js`.
3. **الإعدادات/الأعمدة**: migration أول (أعمدة) ثم فهارس (إن لزم).
4. **لا تعديل دفتر مخزون من خارج `common/stock.ts`**.
5. **كل معاملة مالية**: `db.transaction()` + `common/posting.ts`.
6. **كل استعلام**: parameterized + casts صريحة.
7. **الواجهة**: أي تعديل → `npm run web:build`.
