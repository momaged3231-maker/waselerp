# E5 — الأصول الثابتة والإهلاك (Fixed Assets & Depreciation) — مواصفات تنفيذية

> **الحالة:** تصميم — غير مُنفّذة — الوجود فقط كـ accounts محددة بالمخطط لكن دون balance engine حقيقي

## 1) الهدف

1. إنشاء أصل ثابت بتاريخ شراء فعلي + تكلفة + عمر افتراضي + أي method (straight line أو diminishing balance)
2. إهلاك شهري منتظم لكل أصل (حتى التفرغ المحاسبي)
3. قيد إهلاك: `Dr 5108 / Cr 1202` بقيمة الإهلاك الشهري
4. بيع/انحسار/تفريخ أصل: التخلي عنه بتكلفة رمزية دون impact على P&L نفسه (zero retained effect على الفرع)
5. **خط في الميزانية الختامية للأصول الثابتة** فارغة بالضبط — لا يراها إلا مع `1202 مجمع إهلاك الأصول` في مقابسة عين
6. دعم SWA asset scope يدوي مسبقة بالفئة (مكاتب, حاسبات, أدوات, سيارات, معدات)

## 2) نموذج الأحداث

| الحدث | الجدول/الحركة | المعنى |
|---|---|---|
| تسجيل أصل | `fixed_assets` | الرأس + معرف/كلفة/العمر |
| جدول إهلاك | `asset_depreciation_lines` | تاريخ + تكلفة + journalId |
| توليد قيد شهري | `runDepreciation()` | نفس النمط كالمتوسط `payroll/generate` |
| بيع/انحسار/تفريخ | `asset_disposal` + قيد عكسي | تخلي (نعم/لا، مال/نسبة) |
| تعديل خط الإهلاك | `updateDepreciationLine` (مُبطل بعد الاعتماد) | بغير حركة يدوية |
| جهاز خاسر مع الهالك | `write-off` | إلغاء بتكلفة 0 أو قيمة استبقاء |

## 3) التغييرات على قاعدة البيانات

```sql
CREATE TABLE IF NOT EXISTS fixed_assets (
    asset_id              integer GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    asset_code            varchar(60) NOT NULL UNIQUE,            -- 'AF-2026-000001'
    name                  text NOT NULL,                          -- 'لابتوب Dell Latitude 5500'
    category              varchar(40) NOT NULL,                    -- 'أجهزة كمبيوتر' / 'أثاث' / 'أدوات' / 'سيارات' / 'معدات'
    branch_id             integer NOT NULL REFERENCES branches(branch_id),
    gl_asset_account_id   integer NOT NULL REFERENCES gl_accounts(account_id),   -- عادة 1201
    gl_accumulated_account_id integer NOT NULL REFERENCES gl_accounts(account_id), -- عادة 1202
    cost                  numeric(18,2) NOT NULL,
    residual_value        numeric(18,2) NOT NULL DEFAULT 0,
    useful_life_months    integer NOT NULL CHECK (useful_life_months > 0),
    acquisition_date      date NOT NULL,
    in_service_date       date,
    depreciation_method   smallint NOT NULL DEFAULT 1,              -- 1 straight line · 2 diminishing balance (40% / 20%)
    depreciation_rate_pct numeric(5,2),                            -- للـ diminishing: 20% مثلاً
    expected_end_date     date,                                     -- in_service_date + useful_life
    tag_number            varchar(60),                              -- باركود / QR
    responsible_person    text,                                     -- الاسم المقيد (يدوي)
    supplier_id           integer REFERENCES parties(party_id),
    supplier_invoice_id   bigint REFERENCES invoices(invoice_id),
    status                smallint NOT NULL DEFAULT 1,               -- 1 in-service · 2 idle · 3 sold · 4 disposed · 5 written-off
    gl_asset_journal_id   bigint REFERENCES gl_journals(journal_id), -- قيد الاستحواذ (ثبت من account source)
    notes                 text,
    created_at            timestamptz NOT NULL DEFAULT now(),
    updated_at            timestamptz NOT NULL DEFAULT now()
);

CREATE TABLE IF NOT EXISTS asset_depreciation_lines (
    line_id               bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    asset_id              integer NOT NULL REFERENCES fixed_assets(asset_id) ON DELETE CASCADE,
    period_month          date NOT NULL,                           -- '2026-09-01'
    depreciation_amount   numeric(18,2) NOT NULL,
    accumulated           numeric(18,2) NOT NULL,
    book_value            numeric(18,2) NOT NULL,                  -- cost - accumulated
    journal_id            bigint REFERENCES gl_journals(journal_id),
    posted_at             timestamptz
);
CREATE INDEX IF NOT EXISTS ix_asset_dep_period ON asset_depreciation_lines(period_month);
CREATE INDEX IF NOT EXISTS ix_asset_dep_asset ON asset_depreciation_lines(asset_id);

CREATE TABLE IF NOT EXISTS asset_disposals (
    disposal_id           bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    asset_id              integer NOT NULL REFERENCES fixed_assets(asset_id),
    disposal_date         date NOT NULL,
    disposal_type         smallint NOT NULL DEFAULT 1,               -- 1 بيع · 2 انحسار · 3 تفريخ · 4 خاسر
    disposal_amount       numeric(18,2) NOT NULL DEFAULT 0,          -- 0 للانحسار والخاسر
    gl_journal_id         bigint REFERENCES gl_journals(journal_id),
    reason                text,
    created_at            timestamptz NOT NULL DEFAULT now()
);
```

## 4) القيود المحاسبية المتوقعة

### 4.1 — قيد الاستحواذ (مرة واحدة فقط وقت الإنشاء)

```
Dr  1201  أثاث وتجهيزات          [cost]     شراء عنصر
Cr  2101  ذمم الموردين / 1101 الخزينة   [cost]     دفع نقدي أو آجل
```

(يتم تسجيله من خلال تسجيل الفاتورة المعتادة بمفهوم الأصل تلقائيًا — flag `is_fixed_asset = true` في السطر)

### 4.2 — قيد الإهلاك الشهري (منتظم)

```
Dr  5108  إهلاك الأصول الثابتة   [depreciation_amount]
Cr  1202  مجمع إهلاك الأصول        [depreciation_amount]
```

### 4.3 — قيد البيع (بقليل أو كثير)

```
Dr  1202  مجمع إهلاك الأصول        [accumulated]
Cr  1201  أثاث وتجهيزات           [cost]
Dr  1101  الخزينة أو 1103 ذمم العملاء    [disposal_amount]
Dr/Cr 4104/5106 إيجار آخر/مصروف آخر       [المتبقي]
```

(التطابق يتم via postJournal balance validation — تمنع `assertPeriodOpen` أي قيد غير متوازن)

### 4.4 — قيد تفريخ ("write-off")

```
Dr  1202  مجمع إهلاك الأصول        [accumulated]
Dr  5107  مصروفات مالية           [المتبقي :cost − accumulated]
Cr  1201  أثاث وتجهيزات           [cost]
```

## 5) الصلاحيات

| الدور | الصلاحية |
|---|---|
| المدير/المدير التنفيذي | إنشاء/تعديل/حذف أصل ثابت |
| محاسب (Accountant) | إنشاء/تشغيل الإهلاك الشهري · تصدير تقارير |
| أمين مخزن | إدارة `tag_number` / serial / location |
| كاشير | لا تصل لـ Fixed Asset |

## 6) قواعد التحقق

1. **التكلفة > 0** و `useful_life_months > 0`
2. **قيد الاستراتيجية**: `cost >= residual_value` (إلزامي)
3. **التفريخ**: لا يجوز write-off لأصل مُستهلك فعليا (`book_value = cost — accumulated = 0`)
4. **الفترة مغلقة**: `periods.is_closed = true` يمنع تشغيل الإهلاك لشهر راح فيه القيد
5. **تاريخ الاستحواذ**: لا يسمح بـ acquisition_date بعد today + 1 month (لا قيد ميت)
6. **اجرت علامتان أو قارئتان على asset_code** للتعدد — `UNIQUE (asset_code)`
7. **حفظ<Booking**: لا يمكن الـ disposal conditional إن '$1103 AR' or '1101 cash' ≥ 0


## 8) التقارير

1. **جدول الإهلاك** — كل أصل: cost · accumulated · book_value · عمر متبقي · قيمة استرداد
2. **كشف الإهلاك الشهري** — تقسيم حسب الفئات (كمبيوتر / أثاث / سيارات / معدات) — نفس تقسيم 4-5-class في البيانات
3. **سجل الاستحواذات** (acquisitions log) — مع التكلفة الإجمالية للربع
4. **سجل التفريخ/بيع/ان حسار** — بالفرق في الأصول + خسارة/مكاسب المباشرة
5. **دفتر الأستاذ التفصيلي** — لكل مصروف (5108 + 1202 + الدفتر نفسه)
6. **تقاطع سجل الإهلاك مع الميزانية** — 1201 + 1202 + 5108 (حسابات متعلقة بـ 3 FS)

## 9) الاختبارات الآلية (Regression)

| الاختبار | ما يرى |
|---|---|
| `POST /accounting/assets` بـ CBD 24,000، عمر افتراضي 24 شهور | أوراق تم إنشاؤها، الاستحواذ مسجل |
| `run-depreciation` for month 1 | Dr 5108 1,000 / Cr 1202 1,000 بالضبط |
| بيع أصل بعد 6 أشهر | قيدان: الاسجحاب من 1202 6,000 (تم تحديد accumulated) + جاء 18,000 دخلي
| الأصل صلاحية closed period | يُرفض لسبب «الفترة مغلقة» |
| تعديل التكلفة بعد الأصل مسجل | 400 برسالة «لا يمكن تعديل التكلفة بعد الاعتماد» |
| الـ straight line vs diminishing | استبدل الانتاجية verify exact match بـ formula `cost - residual) / useful_life`, أو `cost * rate` diminishing |

## 11) ما الذي لا أفعله

- لا أقتطع أي أصل في كشف حيازة معين بمال > قيمته دفترية — التصحيح بحاشية مقلقة الحذر
- لا أحسب الإهلاك على البضائع التجارية ولا على ما يُستخدم كسلعة بيع
- لا أدفع قيمة 1202/1201 بواسطة `1202` + `5108` لكل دورة دون ثبت سابق (Insurance rollbacks)
- لا أستخدم `asset_depreciation_lines` لأصل إذن `status = idle` — هو مخرج من الإهادة اليومية، لا يزال الوضع unchanged بلا استثناء
- لا أفهم التفريخ كخفض تدريجي على 4 أشهر — هي ثبت واحدة بحدود الكلفة المتبقية الاتحادية
