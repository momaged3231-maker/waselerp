# WaselERP — Design System MASTER (D17 «ReDesign: Soft Rounded / Navy + Sky»)

> **Status:** نشط — كل شاشة جديدة أو معدّلة **لازم** ترث من القواعد والتوكنز دي.
> أي وكيل قادم: اقرأ الملف ده قبل لمس أي UI. التغييرات الجوهرية على التوكنز لازم تتركز هنا.

## 1) التوجه البصري
- **Soft Rounded** — زوايا دائرية (`rounded-2xl` ≈ 1rem, `rounded-2.5xl` ≈ 1.25rem للكروت)، ظلال ناعمة (`shadow-card`)، مسافات هادئة (4/8px rhythm).
- **Navy + Sky** — هوية مؤسسية هادئة وموثوقة:
  - `--wm-navy` = `#0f172a` (الشريط الجانبي / الخلفيات المعادية)
  - `--wm-sky` = `#0369a1` (الأزرار الأساسية / روابط / تركيز) — نفس `brand-700` في Tailwind
  - `--wm-surface` (`#f8fafc` خلفية الصفحة) · `--wm-card` (`#ffffff`) · `--wm-ink` (`#0f172a`) · `--wm-line` (`#e2e8f0`)
- **عربي RTL أصلًا** — أي شاشة جديدة تُبنى RTL-first، الأرقام والقيم اللاتينية dir="ltr".
- **Tajawal** للنصوص (خط عربي هندسي مريح) + **Rubik** للأرقام (`font-num`) حيث يلزم.

## 2) التوكنز (globals.css)
| التوكن | الاستخدام |
|---|---|
| `--wm-surface / --wm-card` | خلفية التطبيق والكروت (يُقرآن من المتغيرات تلقائيًا) |
| `--wm-ink / --wm-ink-soft` | النص الأساسي والثانوي |
| `--wm-line` | الحدود والفواصل |
| `--wm-sky` | التركيز / الهوية الأساسية |
| `--radius-card` / `--radius-control` | أنصاف أقطار الكروت والعناصر |
| `--shadow-card / --shadow-lift` | الظلال الناعمة |

### الوضع الداكن (جاهز — مش مفعّل)
`:root[data-theme='dark']` معرّفة بكل التوكنز نفسها (بطاقات navy مرفوعة، accent سمائي ساطع).
**ما فيش كسر:** كل المكونات بتقرأ من التوكنز/الأصناف، فأي تفعيل مستقبلي = تغيير `data-theme` + ضبط كلاسات slate على `.card/.input`. لا تُدخل ألوان hex عشوائية — دايمًا عبر التوكنز.

## 3) الأصناف المشتركة (`@layer components`)
- `.card` · `.card-title` — بطاقة قياسية (border + radius + shadow-card)
- `.btn` · `.btn-primary` · `.btn-soft` · `.btn-success` · `.btn-danger` — min-height 40px (44px على اللمس)
- `.input` · `.label` — حقول بنظافة موحدة (radius-2xl, focus ring brand)
- `.table` / `.table-wrap` / `.badge` — جداولRTL مع تظليل هروب + badges rounded-xl

## 4) قواعد التخطيط والاستجابة
- **Breakpoints:** 375 (موبايل صغير) · 768 (تابلت portrait) · 1024 (تابلت landscape / POS) · 1440+ (ديسكتوب)
- **الأهداف اللمسية:** أي زر تفاعلي ≥ 44×44px على `(pointer: coarse)` — طبقة `@media (pointer: coarse)` في globals.css بتفرضه تلقائيًا.
- **الشاشات الكبيرة:** عرض المحتوى يتسع طبيعي بس الجداول `overflow-x-auto`.
- **الطباعة:** `.no-print` وaside/nav/header مخفيين + منطقة `.labels-print-only` للباركود.
- **`viewport`:** `width=device-width, initialScale: 1, viewportFit: cover` — **ممنوع** `userScalable: false` أو `maximumScale` (تكسر التجربة على iPad/التابلت).
- **Safe areas:** `env(safe-area-inset-bottom)` في أسفل القائمة الجانبية/الأشرطة السفلية.
- **الأداء:** صور/أيقونات مشروطة، لا ظلال متحركة على مسارات كبيرة، `prefers-reduced-motion` محترم في globals.css.

## 5) شاشة POS (المعيار بعد D17)
- **التخطيط:** `.pos-grid` — السلة **يمين (موسّعة 360–400px)** والمنتجات تتسع يمين→يسار: `min-width: 1024px` ⇒ `minmax(360px,400px) minmax(0,1fr)` + ارتفاع شبكة `calc(100dvh - 8.5rem)`.
- **شبكة الأصناف:** `grid-cols-2` موبايل → `sm:3` → `xl:4` → `2xl:5`، كروت `pos-item-card` min-h 96px (112px على ≥768px)، اسم الصنف سطرين بحد أقصى، السعر بخط `font-num` متراص.
- **تصفية الأقسام:** شريط chips `الكل + الفئات` فوق الشبكة (فلتري client-side من نتائج البحث).
- **السلة:** أعمدة qty/unit/price/discount بشبكة `grid-cols-12` كما هي لكن بأحجام هدف لمس أكبر؛ إجمالي «المطلوب» بارز بخط `text-brand-700`؛ زر «إتمام البيع» `btn-success` بارتفاع مضاعف.
- **الحالات:** `loading/empty/error` أساسية لكل لوحة — ممنوع شاشة فارغة بلا رسالة.

## 6) الأيقونات
- الأيقونات المت inline SVG داخل `components/icons.tsx` — **لا تُدخل emojis كأيقونات**. أي أيقونة جديدة تُضاف بنفس الأسلوب (24×24، stroke 1.8–2).
- شريط الجانبية في `AppShell` — مجموعات: نظرة عامة / التشغيل / المبيعات / المخازن / المالية / النظام — لا تنشئ مجموعة جديدة إلا بعد استشارة.

## 7) القوائم والإجراءات (Arrangement rules)
- إجراءات المستخدم الشائعة أولًا: أعلى-يمنى على RTL = المكان الثانوي، أقصى اليسار = العمود الأعلى (الرئيسي).
- **شريط الأدوات ثابت** لكل شاشة (title + إجراءات) بنفس النمط: `flex flex-wrap items-center justify-between gap-2`، زر إجراء رئيسي واحد (`.btn-primary`) + إجراءات ثانوية `.btn-soft`.
- **الأزرار الحرجة** (حفظ/حذف/ترحيل) يمين-أو-يسار حسب الأهمية: الإجراء الأساسي أقصى البداية (اليمين في RTL)، «إلغاء» بجانبه.
- **الحذف دائمًا `.btn-danger` أو نص أحمر** + تأكيد دائمًا. لا حذف بلا `window.confirm` أو modal.

## 8) التباين والوصولية
- نص عادي ≥ 4.5:1 على البطاقات، نص كبير ≥ 3:1، حدود/أزرار ≥ 3:1.
- `focus-visible` بإطار brand في كل مكان (لا تعطّله).
- التحذير/الخطأ بلون + أيقونة + نص، ليس بلون فقط.
- `prefers-reduced-motion` مطبق، لا GSAP إلزامي.

## 9) ما هو مؤجل/مرفوض
- **الوضع الداكن:** التوكنز جاهزة — التفعيل يحتاج تمرير على الكلاسات اللصيقة (`bg-white`ـ`text-slate-*` في الشاشات) — جلسة قادمة، لا تلمس الآن.
- **أي جزء لا يستخدم التوكنز/الأصناف المشتركة يُرفض في المراجعة.**
- **ألوان hex عشوائية مرفوضة** — استخدم `sky`/`navy`/`slate`/`brand` من Tailwind أو التوكنز.
