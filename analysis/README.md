# WaselERP — بيانات تشغيلية محلية (غير مكرّرة في Git)

| المجلد | المحتوى | الحالة |
|---|---|---|
| `db/` | مخطط PostgreSQL + سكربتات بذر/تفريغ/بيانات تجريبية | ✅ في Git |
| `docs/` | تحليل البرنامج المرجعي + قرارات المعمارية | ✅ في Git |
| `analysis/db/` | تفريغات قاعدة بيانات البرنامج المرجعي (100 جدول + 319 روتين SQL) | 🔒 **محلي فقط** (مستبعد من `.gitignore`) |

لو محتاج تجديد الملفات دي على جهاز تاني، شغّل من `C:\Users\Server-PC\Desktop\WaselERP` (المسار المحلي).
